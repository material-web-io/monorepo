Navigation rails let people switch between UI views on mid-sized devices. Use a navigation rail in a medium, expanded, large or extra-large window. A rail can contain:

- Three to seven destinations
- A menu button, which expands and collapses the rail
- An optional [FAB](/components/fab), for the key action of the app

Always put the rail in the same place, even on different screens of an app.

On smaller devices, use a [navigation bar](/components/navigation-bar) instead.

A rail is composed of these parts:

| Part                       | Use                                                           |
| -------------------------- | ------------------------------------------------------------- |
| `NavigationRail`           | The rail                                                      |
| `NavigationRailHeader`     | The controls at the top of the rail. See [Header](#header).   |
| `NavigationRailItem`       | A destination                                                 |
| `NavigationRailSection`    | A group of secondary destinations. See [Sections](#sections). |
| `Icon`                     | In an item, its icon, sized and colored by the item           |
| `Text` with `slot="label"` | In an item, its label, which names the item                   |

```tsx
import {
  NavigationRail,
  NavigationRailHeader,
  NavigationRailItem,
  NavigationRailSection,
} from '@material-web/react'
import { Text } from 'react-aria-components'
```

## Basic navigation rail

Put one `NavigationRailItem` per destination in a `NavigationRail`, each with its icon and its label.

<Example {...basic} isFlush />

A rail comes in two variants, collapsed and expanded, which transform into each other when the menu button is selected. Set `isExpanded` to expand the rail, and change it in the `onPress` of the menu button, as the first example does. The page beside the rail adjusts to fit.

### Collapsed rail

A collapsed rail (the default) is 96dp wide, with each item's label under its icon. It runs along the leading edge of the window.

<Example {...collapsed} isFlush />

### Expanded rail

An expanded rail is as wide as its content, from 220 to 360dp, with each item's icon and label side by side. A label too long for that wraps. Use an expanded rail when there are [secondary destinations](#sections) that have lower priority than the main navigation items.

<Example {...expanded} isFlush />

### Section

<NavigationRailSectionSlots showLegend />

| Slot     | Child                          | Use                                  |
| -------- | ------------------------------ | ------------------------------------ |
| `header` | A `Text`, first in the section | The header of a [section](#sections) |

Give the header an `id`, and set the section's `aria-labelledby` to that `id`. Without a header, name the section with an `aria-label`.

## Header

Write a `NavigationRailHeader` first in the rail, then the items, then any sections. The rail shows its children in the order written.

The header shows its children in a column, such as a menu `IconButton` and a [FAB](/components/fab). The first example has both.

| Part        | Use                                                                                                                                                           |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Menu button | Change the menu icon when the rail is expanded, to show that it can be collapsed.                                                                             |
| FAB         | Pass the rail's `isExpanded` to the FAB as its `isExtended`. An extended FAB widens the expanded rail. A FAB in the header has no shadow until it is hovered. |
| Logo        | Optional. Avoid a logo that could be mistaken for a button, and do not use one as the menu button.                                                            |

## Sections

Put secondary destinations in a `NavigationRailSection`, after the rail's own items. A section is shown only in an expanded rail. For a section header, see [Slots](#section).

<Example {...sections} isFlush />

## Selection

Set `isSelected` on the `NavigationRailItem` of the page being shown, and handle a press with `onChange` or `onPress`. A selected item shows the active indicator and fills its `Icon`.

```tsx
<NavigationRailItem isSelected={page === 'inbox'} onChange={() => setPage('inbox')}>
  <Icon name="inbox" />
  <Text slot="label">Inbox</Text>
</NavigationRailItem>
```

- **Your own state:** Selecting an item does not deselect the others, and a press on the selected item calls `onChange(false)`, so keep the selection in your own state.
- **Uncontrolled:** With `defaultSelected` instead, an item keeps its own selection, and a second press turns it off.

## Disabled

Set `isDisabled` to disable an item. It cannot be pressed or focused.

<Example {...disabled} isFlush />

## Arrangement

Set `arrangement` to `top` (the default) or `center`. With `center`, the items are in the middle of the rail, and the header stays at its top. On tablets, use `center` to make the items easier to reach.

<Example {...center} isFlush />

The sections are centered together with the items. This also applies to a collapsed rail, where the sections are hidden but keep their space.

## Placement

The rail is not positioned for you, and is as tall as its container stretches it. Put it first in a row with the page, such as `<div className="flex h-dvh">`, so that it is on the leading edge of the window: the left side in a left-to-right language, and the right side in a right-to-left one.

The rail is not a landmark. Put it in a `<nav>` of your own, with `flex` so that the rail is stretched, as in the first example, or name it with an `aria-label`.

## Hidden when collapsed

Set `isHiddenOnCollapse` to hide the rail while it is collapsed, for an immersive page. A hidden rail takes no space and cannot be reached, so expand it from a menu button of your own, outside the rail. Once expanded, it is shown beside the page, which makes room for it.

<Example {...hiddenOnCollapse} isFlush />

- **Layout:** Such a rail is never shown collapsed, and its sections are always shown.
- **Focus:** Move the keyboard focus to the rail's menu button when it expands, and back to the page's menu button when it collapses.

## Third-party routing library

An item takes no `href`. To move between the pages of an app, call the router in the item's `onChange` or `onPress`, and set `isSelected` from the current location. See [Routing](/get-started/react-aria#routing).

With React Router:

```tsx
import { Icon, NavigationRailItem } from '@material-web/react'
import { Text } from 'react-aria-components'
import { useLocation, useNavigate } from 'react-router'

function InboxItem() {
  const { pathname } = useLocation()
  const navigate = useNavigate()
  return (
    <NavigationRailItem isSelected={pathname === '/inbox'} onPress={() => navigate('/inbox')}>
      <Icon name="inbox" />
      <Text slot="label">Inbox</Text>
    </NavigationRailItem>
  )
}
```

The [navigation bar](/components/navigation-bar#third-party-routing-library) page has a whole example.

## Customization

Pass classes in `className` to restyle the rail, its header, an item or a section. A class of yours replaces the component's own class for the same property. See [Styling](/get-started/styling) for the classes, the states and the theme.

Set `className="bg-transparent"` to turn the rail's fill off, and `className="border-e border-outline-variant"` to show a divider at the edge next to the content.

<Example {...divider} isFlush />

Pass a function as an item's children to render them from its state, as on a [navigation bar](/components/navigation-bar#customization) item: `isHovered`, `isPressed`, `isFocused`, `isFocusVisible`, `isSelected` and `isDisabled`. In this example, an item shows another icon when it is selected.

<Example {...functionChildren} isFlush />

- **States:** Style an item's state with its variant, such as `hover:`, `pressed:` or `selected:`. See [States](/get-started/styling#states).
- **Functions:** The `className` and `style` of a rail, an item and a section can be functions of their state too. See [Children as a function](/get-started/composition#children-as-a-function).
- **Every navigation rail:** To restyle all the navigation rails at once, change the [theme](/get-started/styling#theme).

## Accessibility

### Use cases

Material [lists](https://m3.material.io/components/navigation-rail/accessibility#5a80f844-0997-43d3-88ad-29dd8757ea5d) what people should be able to do with assistive technology:

- Navigate between navigation destinations
- Select a particular navigation destination from a set
- Get appropriate feedback based on input type

### Interaction and style

- **States:** Hovering an item shows a state layer in its indicator's box, and a press anywhere on the item shows a ripple there. Keyboard focus shows a [focus ring](/theme/accessibility#focus-ring) at the item's edges, across the rail, and a click does not. A disabled item shows no state layer.
- **Touch target:** An item takes a press anywhere across the rail, past its indicator in an expanded rail. Its items are 64dp tall in a collapsed rail and 56dp in an expanded one, more than the 48dp minimum [touch target](/theme/accessibility#touch-targets).
- **Color contrast:** With the default colors, the icons keep 3:1 contrast and the labels 4.5:1 with what is behind them, in the light and dark schemes at every contrast level. Material [advises](https://m3.material.io/components/navigation-rail/accessibility#0e7aba92-b082-47cb-a547-982996e6d186) enough contrast between the container and the icons, active or not: check it again when you turn the rail's fill off with `bg-transparent`.
- **Text size:** A collapsed rail's label wraps under its icon as the text grows, and the item grows taller with it. Material [advises](https://m3.material.io/components/navigation-rail/accessibility#88aff451-dd18-4b08-9939-3bbf43564593) keeping the full label visible at up to twice the text size.
- **Motion:** With [reduced motion](/theme/accessibility#reduced-motion), the rail expands and collapses at once, and the active indicator appears at once.
- **Forced colors:** In [forced colors](/theme/accessibility#forced-colors), the active indicator is drawn in the system's highlight color, with the icon and the label on it in the highlight text color, and a disabled item in the gray text color.
- **Right to left:** In a right-to-left direction, the rail's parts are mirrored, and it expands toward the page.
- **Selected icon:** A selected item fills its `Icon`, as Material [advises](https://m3.material.io/components/navigation-rail/accessibility#1409bd2d-4d1a-4ca8-91c4-13cbbe90bb58). For an icon with no filled style, Material advises the semibold weight: give it `font-semibold` while the item is selected. See [Customization](#customization).

### Focus

- Tab moves the focus into the rail once: to its first control, such as the menu button in its header, as Material [advises](https://m3.material.io/components/navigation-rail/accessibility#daf53388-d7f7-4c38-9d2a-3f64abab9b13), or to the control focused last. The next Tab leaves the rail, and Shift+Tab comes back to the control focused last.
- A disabled item cannot be focused, and neither can an item in a section of a collapsed rail, where the section is hidden.
- A rail hidden when collapsed cannot be reached until it expands. Move the focus to it and back yourself, as [Hidden when collapsed](#hidden-when-collapsed) describes.

### Keyboard navigation

| Keys             | Actions                                              |
| ---------------- | ---------------------------------------------------- |
| Tab              | Move the focus into the rail, or out of it           |
| Up or Down arrow | Move the focus to the previous or next control       |
| Space or Enter   | Select the focused item, or press the focused button |

- The up and down arrow keys move between all of its controls, the header's buttons and the items. They skip a disabled or hidden one, and stop at the first and the last.
- An item's `onKeyDown` is not called for the arrow keys, with or without a modifier, and the rail takes no `onKeyDown`.

### Labeling elements

- The rail is a vertical toolbar, and each item a toggle button. Name the rail with an `aria-label`, or put it in a `<nav>`.
- The label names each item, as Material [advises](https://m3.material.io/components/navigation-rail/accessibility#5c621a2e-eeb9-40a9-aea1-bafc1f3426d0). Where the label is ambiguous, Material advises a more descriptive name: set an `aria-label` that includes the label, such as Recent images for an item labeled Recent. For an item with no label, set an `aria-label`.
- A section is a group. Name each section with its header and `aria-labelledby`, or with an `aria-label`.
- Give the menu button an `aria-label` that says what it does, such as Expand or Collapse, as the first example does.
- A selected item reports it with `aria-pressed`.
